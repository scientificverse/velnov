Q59. hard

Which overall statement about numbers and place value is CORRECT?

  1. A Each digit in a number has a place value (ones, tens, hundreds...), and we use these to read, write, compare and order numbers
  2. B Every digit always means the same value
  3. C Bigger numbers always have fewer digits
  4. D Place value has no use

Answer: A — Each digit in a number has a place value (ones, tens, hundreds...), and we use these to read, write, compare and order numbers

This sums up the topic: the value of a digit depends on its place (ones, tens, hundreds), which lets us build, compare (>, <, =) and order numbers, and recognise even and odd numbers.
