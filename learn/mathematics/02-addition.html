Q25. medium

Does the answer change if we add in a different order? 5 + 3 and 3 + 5

  1. A No, both equal 8
  2. B Yes, 5 + 3 is bigger
  3. C Yes, 3 + 5 is bigger

Answer: A — No, both equal 8

In addition, the order does not change the answer: 5 + 3 = 8 and 3 + 5 = 8. This is the order (commutative) property.

Q59. hard

Which overall statement about addition is CORRECT?

  1. A Addition means putting numbers together to find the total; we add ones first, then tens, carrying when a column makes 10 or more
  2. B Addition always makes a smaller number
  3. C The order of numbers changes the total
  4. D We never carry in addition

Answer: A — Addition means putting numbers together to find the total; we add ones first, then tens, carrying when a column makes 10 or more

This sums up the topic: addition combines numbers into a total; we line up ones, tens and hundreds and carry when a column reaches 10; and the order of the numbers does not change the answer.
