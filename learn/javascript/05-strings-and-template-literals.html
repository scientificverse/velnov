Easy questions (9)

Q1. easy

Which quote styles can create a string in JavaScript?

const a = 'hi';
const b = "hi";
const c = `hi`;   // template literal
  1. A Single ' ', double " " and backticks ` `
  2. B Only double quotes
  3. C Only single quotes
  4. D Only backticks

Answer: A — Single ' ', double " " and backticks ` `

Single and double quotes are interchangeable. Backticks create template literals, which additionally support interpolation and multi-line text.

Template literalsQuotes

Q2. easy

What is the output? const name = "Ana"; console.log(`Hello ${name}!`);

console.log(`Hello ${name}!`);      // Hello Ana!
console.log("Hello ${name}!");     // literal - no interpolation
  1. A Hello Ana!
  2. B Hello ${name}!
  3. C Hello name!
  4. D SyntaxError

Answer: A — Hello Ana!

Inside backticks, ${expression} is evaluated and inserted. This is string interpolation - far more readable than "Hello " + name + "!".

Template literalsInterpolation

Q4. easy

How do you create a MULTI-LINE string most easily?

const html = `
  <div>
    <p>Hello</p>
  </div>
`;
  1. A Use backticks - line breaks inside are preserved
  2. B Use \n in single quotes only
  3. C Multi-line strings are impossible
  4. D Use triple quotes

Answer: A — Use backticks - line breaks inside are preserved

Template literals keep real line breaks, so HTML blocks and long messages stay readable. (\n still works inside ordinary quotes.)

Q6. easy

What is the output? console.log("hello"[0], "hello".charAt(1));

  1. A h e - indexing starts at 0
  2. B e l
  3. C h h
  4. D undefined e

Answer: A — h e - indexing starts at 0

Both bracket notation and charAt() read a character by index, counting from 0. Bracket notation returns undefined for out-of-range; charAt returns "".

Q8. easy

What does "hello".toUpperCase() return - and does it change the original?

let s = "hello";
s.toUpperCase();       // result discarded!
console.log(s);         // "hello"
s = s.toUpperCase();   // correct
console.log(s);         // "HELLO"
  1. A "HELLO", and the original is unchanged (strings are immutable)
  2. B "HELLO", and the original becomes uppercase too
  3. C "hello"
  4. D undefined

Answer: A — "HELLO", and the original is unchanged (strings are immutable)

Every string method returns a NEW string; the original can never be modified. You must capture the result: s = s.toUpperCase().

ImmutabilityString methods

Q12. easy

Which method checks whether a string CONTAINS another string?

const s = "hello world";

"hello world".includes("world") returns true/false. Related: startsWith(), endsWith(), and indexOf() (which returns a position or -1).

Q14. easy

console.log(`Total: ${price * qty}`);

The braces hold a full expression, evaluated and converted to a string.

Q7. medium

What does "hello".at(-1) return?

console.log("hello".at(-1));   // "o"
console.log("hello"[-1]);      // undefined
  1. A "o" - at() accepts NEGATIVE indexes counting from the end
  2. B "h"
  3. C undefined
  4. D Error

Answer: A — "o" - at() accepts NEGATIVE indexes counting from the end

at() (ES2022) supports negative indexes, unlike bracket notation. "hello"[-1] gives undefined, but "hello".at(-1) gives the last character.

at()Negative index

Q9. medium

What happens? let s = "hello"; s[0] = "H"; console.log(s);

  1. A "hello" - strings are immutable, so the assignment silently does nothing
  2. B "Hello"
  3. C TypeError
  4. D "H"

Answer: A — "hello" - strings are immutable, so the assignment silently does nothing

You cannot change a character in place. In non-strict mode the assignment is ignored silently; in strict mode it throws. Build a new string instead: "H" + s.slice(1).

ImmutabilityStrings

Q15. medium

What does "a,b,c".split(",") return?

"a,b,c".split(",");    // ["a","b","c"]
"abc".split("");        // ["a","b","c"]
["a","b"].join("-");    // "a-b"
  1. A The array ["a", "b", "c"]
  2. B The string "abc"
  3. C ["a,b,c"]
  4. D undefined

Answer: A — The array ["a", "b", "c"]

split(separator) breaks a string into an ARRAY. split("") splits into individual characters. The reverse operation is array.join(separator).

splitjoin

Answer: A — "bonana" - replace() changes only the FIRST match

replace() with a string replaces one occurrence. Use replaceAll() (ES2021) or a global regex /a/g to replace every match.

Q11. hard

What is the key difference between slice() and substring()?

"hello".slice(-3);       // "llo"
"hello".substring(-3);   // "hello" (treated as 0)
  1. A slice() accepts NEGATIVE indexes (counting from the end); substring() treats them as 0
  2. B They are identical
  3. C substring() is faster
  4. D slice() only works on arrays

Answer: A — slice() accepts NEGATIVE indexes (counting from the end); substring() treats them as 0

slice(-3) takes the last three characters; substring(-3) behaves like substring(0). substring also swaps its arguments if start > end. Prefer slice.

slicesubstring

Q21. hard

How do you REVERSE a string in JavaScript?

const s = "hello";
console.log(s.split("").reverse().join(""));   // "olleh"
  1. A s.split("").reverse().join("") - strings have no reverse() method
  2. B s.reverse()
  3. C s[::-1]
  4. D reverse(s)

Answer: A — s.split("").reverse().join("") - strings have no reverse() method

reverse() is an ARRAY method, so convert to an array, reverse, and join back. ([...s].reverse().join("") also works.)

Q28. hard

What is a tagged template literal? tag`Hello ${name}`

function upper(strings, ...values) {
  return strings.reduce((out, s, i) =>
    out + s + (values[i] ? String(values[i]).toUpperCase() : ""), "");
}
console.log(upper`hi ${"ana"}`);   // "hi ANA"
  1. A A function call where the function receives the string pieces and the interpolated values separately
  2. B An HTML tag
  3. C A comment style
  4. D Invalid syntax

Answer: A — A function call where the function receives the string pieces and the interpolated values separately

Placing a function name before a template literal calls it with (stringsArray, ...values), letting you post-process the result. Libraries use it for styled-components, escaping HTML and internationalisation.

Tagged templatesAdvanced

Q30. hard

What does "cafe\u0301".length reveal about string length?

console.log("😀".length);        // 2 - surrogate pair!
console.log([..."😀"].length);   // 1
  1. A length counts CODE UNITS, so combined characters and emoji can count as more than one
  2. B length always equals the visible characters
  3. C length is always 4
  4. D Unicode is not supported

Answer: A — length counts CODE UNITS, so combined characters and emoji can count as more than one

JavaScript strings are UTF-16 code units. Accented characters built from combining marks, and emoji (which use surrogate pairs), report a length larger than what the eye sees. [...str].length handles emoji better.

UnicodeUTF-16Emoji
