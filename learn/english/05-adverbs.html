Easy questions (3)

Q1. easy

An adverb is a word that usually tells more about a:

  1. A Verb (how, when or where an action happens)
  2. B Noun
  3. C Colour
  4. D Person

Answer: A — Verb (how, when or where an action happens)

An adverb describes a verb, telling us how, when or where an action is done - 'She sang sweetly', 'He came late', 'They played outside'.

Adverbs

Q2. easy

Which word is the adverb in 'He runs quickly'?

  1. A quickly
  2. B He
  3. C runs
  4. D none

Answer: A — quickly

'Quickly' tells us HOW he runs, so it is the adverb. 'Runs' is the verb it describes.

Q57. hard

Which overall statement about adverbs is CORRECT?

  1. A An adverb tells more about a verb - how, when or where an action happens - and many adverbs are formed by adding '-ly' to an adjective
  2. B An adverb names a person
  3. C Adverbs only describe nouns
  4. D Every adverb ends in '-ly'

Answer: A — An adverb tells more about a verb - how, when or where an action happens - and many adverbs are formed by adding '-ly' to an adjective

This sums up the topic: adverbs mostly describe verbs, answering how (manner), when (time), where (place) and how often (frequency); many end in '-ly', but some like fast, soon, here and well do not.
