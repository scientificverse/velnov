Easy questions (5)

Q1. easy

A conjunction is a word that JOINS two words, phrases or sentences. Which is a conjunction?

  1. A and
  2. B run
  3. C happy
  4. D table

Answer: A — and

'And' is a joining word (conjunction). It links words or ideas - 'bread and butter', 'I sang and danced'.

Conjunctions

Q2. easy

Which of these is a conjunction?

  1. A but
  2. B quickly
  3. C green
  4. D book

Answer: A — but

'But' is a conjunction. It joins two ideas that contrast - 'I am tired but happy'.

  3. C because
  4. D or

Answer: A — and

'And' joins two things we both like. 'I like tea and coffee.'

Q21. easy

An interjection is a word that shows a sudden FEELING or emotion. Which is an interjection?

  1. A Wow!
  2. B run
  3. C table
  4. D and

Answer: A — Wow!

'Wow!' is an interjection - it shows surprise or wonder. Interjections usually end with an exclamation mark (!).

Q58. hard

Which overall statement about conjunctions and interjections is CORRECT?

  1. A A conjunction joins words or sentences (and, but, or, because, so); an interjection shows sudden feeling and is followed by an exclamation mark (Oh! Wow! Alas!)
  2. B Both join words
  3. C Both show feelings
  4. D Neither is used in English

Answer: A — A conjunction joins words or sentences (and, but, or, because, so); an interjection shows sudden feeling and is followed by an exclamation mark (Oh! Wow! Alas!)

This sums up the topic: conjunctions are joining words (and, but, or, because, so, although, until), while interjections are feeling words (Wow!, Ouch!, Alas!, Hurray!) usually written with an exclamation mark.
