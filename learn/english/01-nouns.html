Easy questions (9)

Q1. easy

A noun is a word that names a:

  1. A Person, place, animal or thing
  2. B Action
  3. C Colour only
  4. D Number only

Answer: A — Person, place, animal or thing

A noun is a naming word. It names a person (boy), a place (park), an animal (cat) or a thing (ball).

NounsNaming words

Q2. easy

Which word in this sentence is a noun? 'The dog is barking.'

  1. A dog
  2. B is
  3. C barking
  4. D the

Answer: A — dog

'Dog' is the naming word - it names an animal, so it is the noun. 'Barking' is an action word (verb).

NounsIdentify noun

Q3. easy

Which of these words is a noun?

  1. A table
  2. B run
  3. C happy
  4. D quickly

Answer: A — table

'Table' names a thing, so it is a noun. 'Run' is a verb, 'happy' is an adjective and 'quickly' is an adverb.

Nouns

Q10. easy

A noun that names only ONE person or thing is said to be:

  1. A Singular
  2. B Plural
  3. C Proper
  4. D Collective

Answer: A — Singular

A singular noun means just one - one cat, one book, one boy. When there is more than one, the noun becomes plural.

Singular noun

Q11. easy

A noun that names MORE THAN ONE person or thing is said to be:

  1. A Plural
  2. B Singular
  3. C Proper
  4. D Common

Answer: A — Plural

A plural noun means more than one - two cats, many books, several boys. We usually add 's' to make a noun plural.

Plural noun

Q12. easy

What is the plural of 'book'?

  1. A books
  2. B bookes
  3. C bookies
  4. D book

Answer: A — books

For most nouns we add 's' to make the plural: book → books, pen → pens, dog → dogs.

PluralAdd s

Q24. easy

Which sentence has a PLURAL noun?

  1. A The dogs are running.

  3. C A dog is running.
  4. D One dog runs.

Answer: A — The dogs are running.

'Dogs' means more than one dog, so it is plural. The other sentences all name just one dog (singular).

Medium questions (31)

Q4. medium

A noun that names ONE particular person, place or thing and begins with a CAPITAL letter is called a:

  1. A Proper noun
  2. B Common noun
  3. C Collective noun
  4. D Action word

Answer: A — Proper noun

A proper noun names a special, particular thing - like Ravi, Delhi or Monday - and always starts with a capital letter.

Proper noun

Q5. medium

A noun that names any ordinary person, place or thing is called a:

  1. A Common noun
  2. B Proper noun
  3. C Verb
  4. D Adjective

Answer: A — Common noun

A common noun names something in general - like boy, city or day - and does not begin with a capital letter unless it starts a sentence.

Common noun

Q6. medium

Which of these is a PROPER noun?

  1. A India
  2. B country
  3. C river
  4. D girl

Answer: A — India

'India' names one particular country and begins with a capital letter, so it is a proper noun. 'Country', 'river' and 'girl' are common nouns.

Proper noun

Q7. medium

Which of these is a COMMON noun?

  1. A city
  2. B Mumbai
  3. C Ravi
  4. D Sunday

Answer: A — city

'City' names any city in general, so it is a common noun. Mumbai, Ravi and Sunday are proper nouns naming particular things.

Common noun

Q8. medium

The proper noun in this sentence is: 'My friend Sita lives in Chennai.'

  1. A Sita and Chennai
  2. B friend
  3. C lives
  4. D my

Answer: A — Sita and Chennai

'Sita' names a particular person and 'Chennai' names a particular city, so both are proper nouns and both start with capital letters.

Proper nounIdentify

Q13. medium

What is the plural of 'box'?

  2. B boxs
  3. C boxies

Answer: A — boxes

Q14. medium

What is the plural of 'baby'?

  1. A babies
  2. B babys
  3. C babyes
  4. D baby

Answer: A — babies

When a noun ends in a consonant + y, we change 'y' to 'i' and add 'es': baby → babies, lady → ladies, city → cities.

Q32. medium

Nouns can be MASCULINE (male) or FEMININE (female). Which is a masculine noun?

  1. A king
  2. B queen
  3. C girl
  4. D aunt

Answer: A — king

'King' names a male, so it is masculine gender. 'Queen', 'girl' and 'aunt' name females, so they are feminine.

Q51. medium

Q9. hard

Which noun should begin with a CAPITAL letter?

  1. A monday
  2. B chair
  3. C book
  4. D school

Answer: A — monday

Names of days, months, people, places and countries are proper nouns and must start with a capital letter, so 'monday' should be 'Monday'.

Q59. hard

Which overall statement about nouns is CORRECT?

  1. A A noun names a person, place, animal or thing, and can be common or proper, singular or plural, masculine or feminine
  2. B A noun is always an action word
  3. C Nouns never change form
  4. D All nouns begin with capital letters

Answer: A — A noun names a person, place, animal or thing, and can be common or proper, singular or plural, masculine or feminine

This sums up the topic: nouns are naming words; proper nouns take capital letters, plurals usually add 's' or 'es', collective nouns name groups, and nouns show gender as masculine or feminine.
