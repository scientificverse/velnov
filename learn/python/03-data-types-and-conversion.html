Data Types and Conversion – what kind of value is it?

In this overview: The basic data types · Converting between types · Truthy and falsy values · bool is a kind of int · Floats are approximate · Integers have no size limit · Checking types: isinstance() · Common misconceptions · Quick revision · Test your understanding

1. The basic data types

Every value has a type, which decides what you can do with it. type() tells you a value's type.

  • int: whole numbers, e.g. 5, -12.
  • float: numbers with a decimal point, e.g. 3.14.
  • str: text, e.g. "hello".
  • bool: True or False (capital letters).
  • NoneType: the single value None, meaning “no value”.
  • complex: numbers like 2 + 3j.
print(type(5))
print(type(5.0))
print(type("5"))
print(type(True))
print(type(None))
Output<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>

2. Converting between types

Type conversion (casting) changes a value into another type with int(), float(), str() or bool(). Python never mixes strings and numbers on its own.

print(int("12") + 3)
print(str(5) + "5")
print(int(3.9))        # cuts off the decimal, does not round
print(float("7"))
print(int(float("3.5")))
Output15
55
3
7.0
3

Remember: "5" + 5 is a TypeError, and int("3.5") is a ValueError. Convert in two steps: int(float("3.5")).

Mixing int and float

When an int and a float meet in arithmetic, the result is a float.

3. Truthy and falsy values

In a condition, every value counts as true or false. Falsy values are 0, 0.0, "" (empty string), empty containers ([], {}, ()), None and False. Everything else is truthy.

print(bool(""), bool("hi"))
print(bool("False"))     # a non-empty string!
print(bool(0), bool(-1))
print(bool([]), bool([0]))
OutputFalse True
True
False True
False True

4. bool is a kind of int

In Python, True behaves like 1 and False like 0. This makes sum() a quick way to count True values.

print(True + True)
print(isinstance(True, int))
passed = [True, False, True]
print(sum(passed))
Output2
True

5. Floats are approximate

Floats are stored in binary, so many decimals cannot be stored exactly. Never compare floats with ==; use math.isclose().

import math
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(math.isclose(0.1 + 0.2, 0.3))
Output0.30000000000000004
False
True

6. Integers have no size limit

Python's int can grow as large as memory allows, so there is no overflow.

print(2 ** 100)
print(int("ff", 16), int("1010", 2))   # hex and binary
Output1267650600228229401496703205376
255 10

7. Checking types: isinstance()

isinstance(x, int) is the preferred check. It also accepts subclasses and a tuple of types.

print(isinstance(5.0, (int, float)))

Q17. hard

What is the output of: print(0.1 + 0.2 == 0.3)

print(0.1 + 0.2)            # 0.30000000000000004
import math
print(math.isclose(0.1 + 0.2, 0.3))  # True
  1. A True
  2. B False
  3. C Error
  4. D 0.3

Answer: B — False

Floats are stored in binary, and 0.1, 0.2, 0.3 can't be represented exactly - 0.1 + 0.2 is actually 0.30000000000000004. Never compare floats with ==; use math.isclose() or round first.

  • This is true in nearly every language, not just Python.
