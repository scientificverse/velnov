Easy questions (18)

Q1. easy

Who created the Python programming language?

  1. A James Gosling
  2. B Guido van Rossum
  3. C Dennis Ritchie
  4. D Bjarne Stroustrup

Answer: B — Guido van Rossum

Python was created by Guido van Rossum and first released in 1991. James Gosling created Java, Dennis Ritchie created C, and Bjarne Stroustrup created C++.

  • Python is named after the comedy group 'Monty Python', not the snake.

History of Python

Q2. easy

Python is best described as:

  1. A A compiled, low-level language
  2. B An interpreted, high-level language
  3. C A markup language
  4. D A database language

Answer: B — An interpreted, high-level language

Python is a high-level, interpreted language - your code is executed line by line by the Python interpreter instead of being compiled to machine code first. This makes it easy to write and test quickly.

  • Technically Python compiles to bytecode first, but you never have to manage that step.

Q5. easy

Which symbol starts a single-line comment in Python?

# This is a comment
print("Hi")  # comments can follow code too
  1. A //
  2. B #
  3. C /*
  4. D --

Answer: B — #

Everything after # on a line is a comment - Python ignores it. // is used in C/Java/JavaScript, /* */ in C-style languages, and -- in SQL.

Q6. easy

How do you typically write a multi-line comment / documentation string in Python?

def greet():
    """This function prints a greeting."""
    print("Hello")
  1. A Triple quotes """ ... """
  2. B /* ... */
  3. C <!-- ... -->
  4. D ## ... ##

Answer: A — Triple quotes """ ... """

Triple-quoted strings ("""like this""") span multiple lines. Placed right after a function or class definition they become the docstring - Python's built-in documentation.

  • For plain multi-line notes you can also just use # on each line.

Python is case-sensitive. What does that mean?

Q9. easy

How does Python know which lines belong inside an if statement or a loop?

if score > 50:
    print("Pass")    # inside the if
print("Done")        # outside the if
  1. A Curly braces { }
  2. B The keyword 'end'
  3. C Indentation (spaces at the start of the line)
  4. D Semicolons

Answer: C — Indentation (spaces at the start of the line)

Python uses indentation to define code blocks - lines indented under an if/for/def belong to it. Most languages use { } instead; in Python the indentation IS the structure.

  • The standard is 4 spaces per level. Never mix tabs and spaces.

Q14. easy

What does \n mean inside a string?

print("Hello\nWorld")
# Hello
# World
  1. A A literal backslash-n
  2. B A new line
  3. C A tab
  4. D Nothing - it's an error

Answer: B — A new line

\n is an escape sequence meaning 'new line'. When printed, the text after it appears on the next line.

  • Other escapes: \t = tab, \\ = one backslash, \" = a quote inside a string.

Q15. easy

Which escape sequence inserts a TAB space inside a string?

# Ana     21
  1. A \n
  2. B \s
  3. C \t

\t inserts a horizontal tab - useful for aligning columns of text. \n is a newline; \s is not a Python escape sequence.

Q28. hard

What is the difference between an expression and a statement?

y = 2 + 3        # '2 + 3' is an expression,
                  # 'y = 2 + 3' is a statement
  1. A They are the same thing
  2. B An expression produces a value; a statement performs an action
  3. C Expressions are only used in loops
  4. D Statements always return values

Answer: B — An expression produces a value; a statement performs an action

An expression evaluates to a value (2+3, len("hi"), x > 5) and can be used inside other code. A statement is a complete instruction (if, for, x = 5, return) that DOES something but isn't itself a value.

Q29. hard

Python code is actually compiled before running. Into what?

  1. A Machine code for your CPU
  2. B Bytecode, executed by the Python Virtual Machine
  3. C JavaScript
  4. D Assembly language

Answer: B — Bytecode, executed by the Python Virtual Machine

Python source is compiled to bytecode (.pyc files in __pycache__), which the Python Virtual Machine (PVM) then interprets. This is automatic and invisible - which is why Python is still called an interpreted language.

  • The __pycache__ folder you see in projects holds this cached bytecode.
