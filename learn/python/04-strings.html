Q1. easy

What is the output of: s = "python" print(s[0])

s = "python"
#     012345   <- index positions
print(s[0])   # p
print(s[2])   # t
  1. A p
  2. B y
  3. C python
  4. D Error

Answer: A — p

String indexing starts at 0: s[0] is the FIRST character 'p', s[1] is 'y', and so on.

Q2. easy

What is the output of: s = "python" print(s[-1])

s = "python"
print(s[-1])   # n (last)
print(s[-2])   # o (second last)
  1. A p
  2. B n
  3. C o
  4. D Error

Answer: B — n

Negative indexes count from the END: s[-1] is the last character 'n', s[-2] is 'o'. Very handy for grabbing the end without knowing the length.

Q4. easy

What is the output of: print("python"[:3])

s = "python"
print(s[:3])   # pyt
print(s[3:])   # hon
print(s[:])    # python (full copy)
  1. A pyt
  2. B pyth
  3. C hon
  4. D Error

Answer: A — pyt

Leaving out the start means 'from the beginning': [:3] takes indexes 0, 1, 2 -> 'pyt'. Similarly [3:] means 'from index 3 to the end' -> 'hon'.

Q9. easy

What does " hello ".strip() return?

s = "  hello  "
print(s.strip())    # 'hello'
print(s.lstrip())   # 'hello  '
print(s.rstrip())   # '  hello'
  1. A "hello"
  2. B " hello"
  3. C "hello "
  4. D "h e l l o"

Answer: A — "hello"

.strip() removes whitespace (spaces, tabs, newlines) from BOTH ends of a string - the middle is untouched. lstrip() and rstrip() do only the left or right side.

  • Always strip() user input - people love typing stray spaces.

Q10. easy

What does "a,b,c".split(",") return?

print("a,b,c".split(","))    # ['a', 'b', 'c']
print("one two  three".split()) # ['one', 'two', 'three']
  1. A "abc"
  2. B ['a', 'b', 'c']
  3. C ('a', 'b', 'c')
  4. D 'a' 'b' 'c'

Answer: B — ['a', 'b', 'c']

.split(separator) cuts a string into a LIST of pieces. "a,b,c".split(",") gives ['a', 'b', 'c']. With no argument, split() cuts on any whitespace.

Q12. easy

What does "banana".replace("a", "o") return?

print("banana".replace("a", "o"))     # bonono
print("banana".replace("a", "o", 1))  # bonana
  1. A bonono
  2. B bonana
  3. C banana
  4. D bonan

Answer: A — bonono

.replace(old, new) replaces EVERY occurrence by default: all three a's become o's -> 'bonono'. A third argument limits the count: replace("a", "o", 1) -> 'bonana'.

Q15. easy

name = "Ana" Which line prints: Hello Ana! using an f-string?

name = "Ana"
print(f"Hello {name}!")   # Hello Ana!
print("Hello {name}!")    # Hello {name}!  (no f!)
  1. A print(f"Hello {name}!")
  2. B print("Hello {name}!")
  3. C print(f"Hello name!")
  4. D print("Hello" + {name})

Answer: A — print(f"Hello {name}!")

An f-string starts with f before the quote and fills in {expressions}: f"Hello {name}!" -> Hello Ana!. Option B lacks the f, so it prints the braces literally.

  • f-strings (Python 3.6+) are the modern, preferred way to format text.

Q3. medium

What is the output of: s = "python" print(s[1:4])

s = "python"
print(s[1:4])   # yth (indexes 1,2,3)

  1. A yth
  2. B ytho
  3. C pyt
  4. D tho

Answer: A — yth

Slicing s[start:end] takes characters from index start UP TO BUT NOT INCLUDING end: indexes 1, 2, 3 -> 'yth'. The end index is always excluded.

  • Remember: the slice grabs (end - start) characters.

Q6. medium

What is the classic one-liner to REVERSE a string s?

s = "python"
print(s[::-1])   # nohtyp
  1. A s.reverse()
  2. B reverse(s)
  3. C s[::-1]
  4. D s[-1:1]

Answer: C — s[::-1]

A step of -1 walks the string backwards: s[::-1] returns the reversed string. Strings have no .reverse() method (lists do).

  • Famous interview question: check palindrome with s == s[::-1].

print(", ".join(words))  # a, b, c

  2. B a-b-c
  3. C -abc-

Answer: B — a-b-c

.join() is the opposite of split(): it glues a list of strings together using the string it's called on as the separator: "-".join(...) -> a-b-c.

  • The separator comes FIRST - a common point of confusion.

Q13. medium

What is the difference between find() and index() on strings?

s = "hello"
print(s.find("ll"))    # 2
print(s.find("xy"))    # -1
# s.index("xy")         # ValueError!
  1. A No difference
  2. B find() returns -1 when not found; index() raises ValueError
  3. C index() returns -1; find() raises an error
  4. D find() only works on numbers

Answer: B — find() returns -1 when not found; index() raises ValueError

Both return the position of a substring. When the substring is absent, find() politely returns -1 while index() raises ValueError. Use find() when absence is normal.

Q17. medium

What happens with: s = "hello" s[0] = "H"

s = "hello"
# s[0] = "H"          # TypeError!
s = "H" + s[1:]       # build a new string
print(s)               # Hello
  1. A s becomes "Hello"
  2. B TypeError - strings are immutable
  3. C s becomes "H"
  4. D Nothing

Answer: B — TypeError - strings are immutable

Strings CANNOT be changed in place - assigning to a character raises TypeError. To 'change' a string you build a new one: "H" + s[1:].

  • Immutability is why all string methods RETURN a new string.

Q23. medium

  1. A True
  2. B False

Q24. hard

What do ord("A") and chr(66) return?

print(ord("A"))   # 65
print(chr(66))     # B
print(chr(ord("a") + 1))  # b
  1. A 65 and "B"
  2. B "A" and 66
  3. C 1 and "66"
  4. D Error for both

Answer: A — 65 and "B"

ord() gives a character's Unicode number (A = 65) and chr() does the reverse (66 = B). They're inverses: chr(ord("A")) is "A" again.

  • Used in Caesar ciphers and character math puzzles.

Q30. hard

s = "madam" - which expression checks if s is a palindrome?

s = "madam"
print(s == s[::-1])   # True

s = "python"
print(s == s[::-1])   # False
  1. A s == s[::-1]
  2. B s.palindrome()
  3. C s == reverse(s)
  4. D s[::-1] == True

Answer: A — s == s[::-1]

A palindrome reads the same backwards. s[::-1] is the reversed string, so comparing it to the original does the check in one line. There's no built-in palindrome() or reverse() function for strings.
