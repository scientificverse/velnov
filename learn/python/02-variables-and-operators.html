Easy questions (16)

Q1. easy

Which of the following is a valid variable name in Python?

_total = 100      # valid
count2 = 5        # valid
# 2count = 5      # SyntaxError
# class = 'math'  # SyntaxError: keyword
  1. A 2count
  2. B my-var
  3. C _total
  4. D class

Answer: C — _total

Variable names must start with a letter or underscore, cannot contain hyphens, and cannot be reserved keywords. "_total" is valid. "2count" starts with a digit, "my-var" contains a hyphen, and "class" is a keyword.

  • By convention, use snake_case: student_name, total_marks.

Q2. easy

What is the output of: x = 5 y = x x = 10 print(y)

x = 5
y = x     # y refers to 5
x = 10    # only x changes
print(y)  # 5
  1. A 10
  2. B 5
  3. C Error
  4. D None

Answer: B — 5

y = x makes y refer to the value 5. Reassigning x to 10 later does not change y - numbers are immutable, and y still points to 5.

Q3. easy

Are total and Total the same variable in Python?

  2. B No - Python is case-sensitive, they are two different variables
  3. C Only inside functions
  4. D Only if declared with var

Python is case-sensitive: total, Total and TOTAL are three separate variables. Using the wrong capitalization gives a NameError.

Python unpacks the values left to right: a gets 1, b gets 2. This is called tuple unpacking and works with any matching number of values.

Q8. easy

What does x += 3 mean?

Q9. easy

What is the output of: print(7 // 2)

  2. B 3
  3. C 4
  4. D 3.0

Q10. easy

What is the output of: print(7 % 2)

print(10 % 3)   # 1
print(8 % 2)    # 0  (even numbers % 2 == 0)
  1. A 3
  2. B 3.5
  3. C 1
  4. D 0

Answer: C — 1

% is the modulo operator - it gives the REMAINDER after division. 7 divided by 2 is 3 remainder 1, so 7 % 2 = 1.

  • n % 2 == 0 is the standard test for even numbers.

Q14. easy

How do you force the addition to happen first in 2 + 3 * 4?

  1. A Write it as (2 + 3) * 4
  2. B Use the keyword 'first'
  3. C Put it on a separate line

Q15. easy

What is the difference between = and == ?

x = 5          # assignment
print(x == 5)  # True (comparison)
print(x == 7)  # False
  1. A No difference
  2. B = assigns a value; == compares two values
  3. C == assigns a value; = compares
  4. D == is only for strings

Answer: B — = assigns a value; == compares two values

One equals sign stores a value in a variable (x = 5). Two equals signs ask a question - are these equal? - and give True or False (x == 5).

  • Writing if x = 5: instead of if x == 5: is a SyntaxError in Python.

Q6. medium

What is the output of: a, b = 5, 10 a, b = b, a print(a, b)

a, b = 5, 10
a, b = b, a     # swap!
print(a, b)     # 10 5
  1. A 5 10
  2. B 10 5
  3. C 10 10
  4. D Error

Answer: B — 10 5

a, b = b, a swaps the two variables in one line - the right side (10, 5) is built first, then unpacked. Most languages need a temporary third variable for this.

  • This one-line swap is a favorite Python interview question.

UnpackingSwapping

Q7. medium

After: x = y = z = 7 - what are the values?

x = y = z = 7
print(x, y, z)   # 7 7 7
  1. A Only z is 7; x and y are undefined
  2. B x, y and z are all 7
  3. C Error - chained assignment is not allowed
  4. D x is 7, y and z are None

Answer: B — x, y and z are all 7

Chained assignment gives the same value to every name in the chain: all three variables now refer to 7.

  • Careful with mutable objects: x = y = [] makes BOTH names share ONE list.

AssignmentReferences

Q26. medium

What does the global keyword do inside a function?

count = 0

def increment():
    global count
    count += 1

increment()
print(count)  # 1
  1. A Creates a new local variable
  2. B Lets the function modify a variable defined at module level
  3. C Makes the variable visible to other files
  4. D Declares a constant

Answer: B — Lets the function modify a variable defined at module level

Assigning inside a function normally creates a LOCAL variable. global tells Python the name refers to the module-level variable, so the function modifies the global one.

  • Prefer return values over globals - easier to test and debug.

ScopeLEGB rule

Q20. hard

What is the output of: result = 0 or "hello" print(result)

print(0 or "hello")    # hello
print("hi" or "bye")   # hi (first truthy wins)
print(0 and "hello")   # 0 (and stops at first falsy)
  1. A 0
  2. B True
  3. C hello
  4. D Error

Answer: C — hello

or returns the FIRST truthy value (not just True/False!). 0 is falsy, so or moves on and returns "hello" itself. This is called short-circuit evaluation.

  • Common use: name = user_input or "Guest" (default value).

Short-circuit evaluationTruthiness

Q21. hard

What is the output of: print(-7 // 2)

print(7 // 2)    # 3
print(-7 // 2)   # -4  (not -3!)
  1. A -3
  2. B -3.5
  3. C -4
  4. D 4

Answer: C — -4

Floor division rounds DOWN (toward negative infinity), not toward zero. -7 / 2 = -3.5, and rounding DOWN gives -4. This surprises people from C/Java where -7/2 truncates to -3.

Q27. hard

What is the difference between == and is?

a = [1, 2]
b = [1, 2]
print(a == b)   # True  - same values
print(a is b)   # False - two separate lists
print(a is None) # False - the correct use of is
  1. A They are identical
  2. B == compares values; is checks if both names point to the SAME object in memory
  3. C is compares values; == checks memory
  4. D is only works with numbers

Answer: B — == compares values; is checks if both names point to the SAME object in memory

== asks 'do these have equal values?'. is asks 'are these literally the same object?'. Two equal lists are == but not is. Use is only for None checks.

  • Always write: if x is None: (not == None).

Q28. hard

What is the output of: print(round(2.5), round(3.5))

print(round(2.5))   # 2
print(round(3.5))   # 4
print(round(2.6))   # 3 (normal rounding)
  1. A 3 4
  2. B 2 4
  3. C 3 3
  4. D 2 3

Answer: B — 2 4

Python uses banker's rounding: exact halves round to the nearest EVEN number. round(2.5) -> 2, round(3.5) -> 4. This reduces bias when rounding many values.
