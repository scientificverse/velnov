What is the output? s = "hello" print(s[::-1])

  1. A olleh
  2. B hello
  3. C hell

Q1. hard

What is the output? def f(a, b=[]): b.append(a) return b print(f(1)) print(f(2))

def f(a, b=None):
    if b is None:
        b = []
    b.append(a)
    return b
  1. A [1] then [1, 2] - the default list is created ONCE and reused across calls
  2. B [1] then [2]
  3. C [1, 2] then [1, 2]
  4. D Error

Answer: A — [1] then [1, 2] - the default list is created ONCE and reused across calls

The mutable default argument trap. The default [] is created once at definition and shared by every call that omits b, so it accumulates. Fix: use b=None and create the list inside.

Mutable defaultsCommon traps

Q2. hard

What is the output? print(0.1 + 0.2 == 0.3)

import math
print(math.isclose(0.1 + 0.2, 0.3))   # True
  1. A False - floating-point rounding makes 0.1 + 0.2 = 0.30000000000000004
  2. B True
  3. C Error
  4. D 0.3

Answer: A — False - floating-point rounding makes 0.1 + 0.2 = 0.30000000000000004

Floats are binary approximations; 0.1 and 0.2 can't be represented exactly. Never compare floats with ==; use math.isclose(a, b) or round to a few decimals.

Q3. hard

What is the output? a = [1, 2, 3] b = a b.append(4) print(a)

  1. A [1, 2, 3, 4] - a and b are two names for the SAME list
  2. B [1, 2, 3]
  3. C [4]
  4. D Error

Answer: A — [1, 2, 3, 4] - a and b are two names for the SAME list

b = a does not copy; both names reference one list. Mutating through b is visible through a. For an independent copy: b = a.copy() or b = a[:].

ReferencesAliasing

Q4. hard

What is the output? print(2 ** 3 ** 2)

  1. A 512 - ** is right-associative, so it's 2 ** (3 ** 2) = 2 ** 9
  2. B 64 - (2 ** 3) ** 2
  3. C 12
  4. D 18

Answer: A — 512 - ** is right-associative, so it's 2 ** (3 ** 2) = 2 ** 9

Exponentiation groups right-to-left (unlike most operators). So 3 ** 2 = 9 first, then 2 ** 9 = 512. A favorite precedence gotcha.

Operator precedenceAssociativity

Q5. hard

What is the output? print(True == 1, False == 0, True + True)

  1. A True True 2 - bool is a subclass of int (True is 1, False is 0)
  2. B False False 0
  3. C True True True
  4. D Error

Answer: A — True True 2 - bool is a subclass of int (True is 1, False is 0)

Booleans ARE integers under the hood: True equals 1, False equals 0, and they do arithmetic. That's why sum([True, False, True]) counts the Trues (2).

bool as intTruthiness

Q6. hard

What is the output? print([] == False, bool([]) == False)

  1. A False True - an empty list is falsy but NOT equal to False
  2. B True True
  3. C False False
  4. D Error

Answer: A — False True - an empty list is falsy but NOT equal to False

[] == False compares a list to a boolean (different values) -> False. But bool([]) converts the empty list to False first -> True. Truthiness (used by if) is different from == equality.

Truthiness vs equality

Q11. hard

What is the output? def f(): try: return 1 finally: return 2 print(f())

  1. A 2 - finally's return OVERRIDES the try's return
  2. B 1
  3. C 1 then 2
  4. D Error

Answer: A — 2 - finally's return OVERRIDES the try's return

finally always runs, and its return replaces the pending one from try. This is why returning inside finally is discouraged - it silently swallows the real result (and even exceptions).

try/finallyreturn

Q12. hard

What is the output? print(3 * "ab" + "c")

  1. A ababcabc
  2. B abababc
  3. C ababab c
  4. D Error

Answer: B — abababc

* binds tighter than +: 3 * "ab" = "ababab" first, then + "c" -> "abababc". Precedence applies to string operators too.

Operator precedenceString operations

Q13. hard

What is the output? x = [1, 2, 3] y = x[:] y.append(4) print(x, y)

  1. A [1, 2, 3] [1, 2, 3, 4] - x[:] made an independent copy
  2. B [1, 2, 3, 4] [1, 2, 3, 4]
  3. C [1, 2, 3] [4]
  4. D Error

Answer: A — [1, 2, 3] [1, 2, 3, 4] - x[:] made an independent copy

x[:] creates a shallow copy, so y is a separate list. Appending to y leaves x unchanged. (Contrast with y = x, which would share the list.)

SlicingCopying

Q14. hard

What is the output? print(bool("False"), bool("0"), bool(0), bool(""))

  1. A True True False False
  2. B False False False False
  3. C True True True True
  4. D False True False True

Answer: A — True True False False

Any NON-EMPTY string is truthy - even "False" and "0". Only the empty string is falsy. The number 0 is falsy. So: True, True, False, False.

Q15. hard

What is the output? a = (1, 2, [3, 4]) a[2].append(5) print(a)

  1. A (1, 2, [3, 4, 5]) - the tuple is immutable but its inner LIST is mutable
  2. B Error - tuples can't change
  3. C (1, 2, [3, 4])
  4. D (1, 2, 3, 4, 5)

Answer: A — (1, 2, [3, 4, 5]) - the tuple is immutable but its inner LIST is mutable

A tuple can't have its elements REPLACED, but if an element is itself mutable (a list), that object can still be modified. Immutability is shallow.

Tuple immutabilityMutable elements

range(0) and range(5,5) produce nothing. range(3, 0) is also empty because it counts UP by default and 3 is already past 0 - you'd need range(3, 0, -1) to count down.

  3. C Error

Iterating a dict directly gives its KEYS (['a', 'b']); .values() gives the values ([1, 2]). A frequent point of confusion when looping dicts.

Q24. hard

What is the output? print(list(map(lambda x: x**2, filter(lambda x: x % 2, range(6)))))

  1. A [1, 9, 25] - keep odds (1,3,5), then square them
  2. B [0, 4, 16]
  3. C [1, 4, 9, 16, 25]
  4. D [0, 1, 4, 9, 16, 25]

Answer: A — [1, 9, 25] - keep odds (1,3,5), then square them

filter keeps values where x % 2 is truthy (odd): 1, 3, 5. map squares them: 1, 9, 25. Read inside-out. A comprehension would be [x**2 for x in range(6) if x % 2].

map()filter()lambda

Q25. hard

What is the output? a = b = [1, 2] a += [3] print(a, b)

  1. A [1, 2, 3] [1, 2, 3] - += mutates the shared list in place
  2. B [1, 2, 3] [1, 2]
  3. C [1, 2] [1, 2, 3]
  4. D Error

Answer: A — [1, 2, 3] [1, 2, 3] - += mutates the shared list in place

a and b point to the same list. For lists, += calls extend (in-place mutation), so both names see [1, 2, 3]. (For an int, += would rebind and NOT affect the other name.)

Q28. hard

What is the output? print(max("apple", "banana", key=len), max("apple", "banana"))

  1. A banana banana - one by LENGTH, the other alphabetically (b > a)
  2. B apple apple
  3. C banana apple
  4. D apple banana

Answer: A — banana banana - one by LENGTH, the other alphabetically (b > a)

With key=len, max compares lengths: 'banana' (6) wins. Without key, max compares alphabetically: 'banana' > 'apple' because 'b' > 'a'. Both give 'banana' here, for different reasons.

Q29. hard

What is the output? print(type([]) == list, type([]) is list, isinstance([], list))

  1. A True True True - all three confirm [] is a list
  2. B True False True
  3. C False False True
  4. D Error

Answer: A — True True True - all three confirm [] is a list

type([]) is the list class. == compares it to list (True); is checks identity - and classes are singletons, so True; isinstance is the preferred check (True). All three agree here, but isinstance is best because it respects subclasses.

type()isinstance()

Q30. hard

The famous one - what is the output? for i in range(3): pass print(i)

  1. A 2 - the loop variable survives with its LAST value after the loop
  2. B 3
  3. C NameError
  4. D 0

Answer: A — 2 - the loop variable survives with its LAST value after the loop

Unlike comprehensions, a for-loop variable leaks into the surrounding scope and keeps its final value (2, the last item of range(3)). If range were empty, i would never be defined.

Loop variable scopeGotchas
