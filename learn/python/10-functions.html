Functions – reusable blocks of code

In this overview: Defining and calling a function · return vs print · Default and keyword arguments · *args and **kwargs · Returning several values · Scope: local and global · The mutable default trap · Lambda functions and sort keys · Recursion · Functions are objects · Common misconceptions · Quick revision · Test your understanding

1. Defining and calling a function

A function is a named block of code that runs when you call it. You define it with def; its body runs only when it is called.

def greet(name):
    print(f"Hello, {name}!")

greet("Ana")
greet("Ben")
OutputHello, Ana!
Hello, Ben!

Remember: In def greet(name), name is a parameter. In greet("Ana"), "Ana" is an argument.

2. return vs print

return sends a value back to the caller, so the result can be stored and reused. A function with no return gives back None.

def add(a, b):
    return a + b

total = add(2, 3) * 10
print(total)

def show(a, b):
    print(a + b)

result = show(2, 3)
print(result)
Output50
5
None

Remember: return exits the function immediately; code after it in the same branch never runs.

3. Default and keyword arguments

  • A default value is used when the caller leaves the argument out.
  • A keyword argument is passed by name, so the order doesn't matter.
  • Parameters with defaults must come after those without.
def book(seat, meal="veg"):
    print(seat, meal)

book("12A")
book("12A", "non-veg")
book(meal="none", seat="3C")
Output12A veg
12A non-veg
3C none

4. *args and **kwargs

  • *args collects any number of extra positional arguments into a tuple.
  • **kwargs collects extra keyword arguments into a dict.
def total(*args):
    return sum(args)

print(total(1, 2, 3), total(5))

def config(**kwargs):
    for key, value in kwargs.items():
        print(key, "=", value)

config(theme="dark", size=12)
Output6 5
theme = dark
size = 12

5. Returning several values

Returning several values really returns one tuple, which you can unpack.

def stats(nums):
    return min(nums), max(nums)

lo, hi = stats([3, 8, 1])
print(lo, hi)
Output1 8

6. Scope: local and global

Variables created inside a function are local: they exist only while the function runs. Functions can read global variables, but assigning to one needs the global keyword. Usually it is better to pass values in and return them.

x = 5
def show():
    print(x)        # reading a global is fine
show()

count = 0
def inc():
    global count
    count += 1
inc()
print(count)
Output5
1

Remember: Assigning to a name anywhere in a function makes it local for the whole function. Reading it before the assignment gives UnboundLocalError.

7. The mutable default trap

A default value is created once, when the function is defined. A default list is therefore shared between calls. Use None and create the list inside.

def add_bad(item, lst=[]):
    lst.append(item)
    return lst
print(add_bad(1), add_bad(2))

def add_good(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
print(add_good(1), add_good(2))
Output[1, 2] [1, 2]
[1] [2]

8. Lambda functions and sort keys

A lambda is a small nameless function with a single expression. It is most often used as a key for sorting.

double = lambda x: x * 2
print(double(5))
words = ["banana", "fig", "apple"]
print(sorted(words, key=len))
students = [("Ana", 92), ("Ben", 85)]
print(sorted(students, key=lambda s: s[1]))
Output10
['fig', 'apple', 'banana']
[('Ben', 85), ('Ana', 92)]

9. Recursion

A recursive function calls itself on a smaller problem, and must have a base case that stops it. Without one, Python raises RecursionError (the default limit is about 1,000 calls).

def factorial(n):
    if n <= 1:          # base case
        return 1
    return n * factorial(n - 1)

print(factorial(5))
Output120

10. Functions are objects

Functions can be stored in variables, kept in lists, passed to other functions and returned. This is called being first-class.

def shout(text):
    return text.upper()

def apply(func, value):
    return func(value)

f = shout                     # no brackets: the function itself
print(f("hi"))
print(apply(len, "hello"))
OutputHI
5

Example: Type hints such as def add(a: int, b: int) -> int: document the expected types, but Python does not enforce them.

11. Common misconceptions

print and return do the same job.print only shows a value; return gives it back for further use.
A default list starts fresh on every call.It is created once and shared; use None as the default.
Variables made inside a function exist outside it.They are local and disappear when the function ends.
def f(a=1, b): is fine.Parameters with defaults must come after required ones.
Type hints stop wrong types at runtime.Python ignores them at runtime; tools like mypy check them.

Q4. easy

What is the difference between print() and return in a function?

def add(a, b):
    return a + b

  1. A None - they do the same

Answer: B — print shows a value on screen; return sends the value back to the caller for further use

Q18. easy

What does return do the moment it executes?

def check(n):

    print("never runs")
  1. A Pauses the function
  2. B Immediately EXITS the function, handing back the value - remaining lines don't run
  3. C Prints the value
  4. D Restarts the function

Answer: B — Immediately EXITS the function, handing back the value - remaining lines don't run

return ends the function on the spot. Code after an executed return is unreachable. Multiple returns are fine - typically one per branch.

Q25. easy

By PEP 8 convention, function names should be written as:

  1. A snake_case: calculate_total()
  2. B CamelCase: CalculateTotal()
  3. C ALLCAPS: CALCULATETOTAL()
  4. D kebab-case: calculate-total()

Answer: A — snake_case: calculate_total()

Functions and variables use snake_case; CamelCase is reserved for class names; ALL_CAPS for constants. (kebab-case is illegal - hyphens mean subtraction.)

Answer: A — Reuse, readability, easier testing, and no copy-pasted code

Q21. medium

What is recursion?

def factorial(n):
    if n == 0:          # base case
        return 1
    return n * factorial(n - 1)

print(factorial(5))   # 120
  1. A A function that calls ITSELF, with a base case to stop
  2. B A loop inside a function
  3. C Calling two functions at once
  4. D A function without a return

Answer: A — A function that calls ITSELF, with a base case to stop

A recursive function solves a problem by calling itself on a smaller piece, stopping at a base case. Classic example: factorial(n) = n * factorial(n-1), stopping at factorial(0) = 1.

RecursionBase case

Q16. hard

Why does this raise UnboundLocalError? count = 0 def inc(): count = count + 1 inc()

count = 0
def inc():
    global count
    count += 1     # now legal

# better style:
def inc(count):
    return count + 1

  2. B The assignment makes count LOCAL for the whole function, so 'count + 1' reads a local that has no value yet
  3. C Functions can't use numbers
  4. D inc needs a parameter

Q17. hard

THE classic Python trap - what is the output? def add(item, lst=[]): lst.append(item) return lst print(add(1)) print(add(2))

def add(item, lst=None):
    if lst is None:
        lst = []       # fresh list per call
    lst.append(item)
    return lst
  1. A [1] then [2]
  2. B [1] then [1, 2] - the SAME default list is reused between calls
  3. C [1, 2] then [1, 2]
  4. D Error

Answer: B — [1] then [1, 2] - the SAME default list is reused between calls

Default values are created ONCE, at function definition - not per call. Every call without lst shares the same list, which keeps growing. Fix: default to None and create the list inside.
